## 1. Twiller (X Clone)
**Description:** A robust full-stack social media platform featuring audio tweets, tiered subscriptions with Razorpay integration, and automated security workflows. Standard social platforms often lack granular control over feature access; Twiller solves this with time-gated interactions and usage-based limits.
- **Problem:** Standard social platforms lack granular control over feature access and time-gated interactions.
- **Metric:** Integrated 15+ complex API endpoints.
- **Skills:** Next.js, Express.js, MongoDB, Firebase, Razorpay, Tailwind CSS
- **Live Demo:** [https://twiller-ruby.vercel.app/](https://twiller-ruby.vercel.app/)

## 2. Brahmi Script Recognizer
**Description:** AI-powered web app that recognizes ancient Brahmi script from uploaded images and transliterates them into Telugu, Tamil, and Devanagari/Hindi.
- **Problem:** Ancient Brahmi characters are largely unreadable by modern OCR tools.
- **Metric:** 94% recognition accuracy.
- **Skills:** Computer Vision, React, Flask, TensorFlow, Keras, OpenCV
- **Live Demo:** [https://brahmi-script-evolution.vercel.app/](https://brahmi-script-evolution.vercel.app/)

## 3. Deepfake Detection System
**Description:** Real-time deepfake detection pipeline using ResNet18 and OpenCV, built for frame-level analysis and practical media authenticity verification.
- **Problem:** Manipulated media is increasingly difficult to detect at scale.
- **Metric:** 92% detection accuracy.
- **Skills:** Deep Learning, Python, OpenCV, ResNet18, PyTorch
